# 局域网共享与协作画布

## 连接设备

在「设置 > 局域网共享」中启动共享服务。在「本机设备名称」输入名称并保存，在线时发现列表会随新的 mDNS 广告更新，无需重启。清空后使用系统设备名称。Windows 桌面端以 SMBIOS 系统 UUID 的规范小写文本为输入，计算 SHA-256 并显示为 64 位十六进制设备 ID，身份文件保存在 Windows 默认「文档」目录下的 `MoyuCanvas/identity.json`。私钥仍随机生成并加密保存在身份目录中，用于 TLS 公钥固定；设备 ID 本身不是身份凭据。重装软件或系统、切换工作区不会改变同一主板的 ID；更换主板、固件报告无效 UUID 或虚拟机复制固件 UUID 时可能改变或重复 ID。由旧版本升级的设备会从公钥指纹 ID 切换到 SMBIOS ID，其他设备需要与它重新配对一次；后续使用中不会因重装软件、系统或切换工作区而改变。更换工作区不会清除证书密钥；如果身份密钥文件丢失，需要使用新密钥重新与设备配对。本机设备名称只用于显示，给其他设备设置的本地备注与本机名称相互独立。

共享服务启动时会尝试在每块可用网卡的私有 IPv4 地址上监听；某个地址绑定失败时，其余成功监听的地址仍可使用。支持多播的网卡分别发布 mDNS 服务，并每 20 秒重新查询一次。对于无法传递 mDNS 的虚拟网卡等链路，设备还会每 10 秒向各已监听网卡所在子网的定向广播地址发送 UDP 47876 发现信息；它不会向所有网段或跨路由器广播。发现包只用于显示设备地址，配对仍须核对设备 ID、TLS 公钥与配对码。设置页列出实际监听地址和本机 mDNS 注册状态，后者不保证对端能收到组播。启动后若新增或移除网卡，关闭再开启共享服务以刷新监听列表。虚拟网卡或 VPN 网卡如具备私有 IPv4 地址，也可能参与发现；请按实际网络连接和防火墙设置控制可达范围。

同一局域网中的设备会尝试自动发现；发现不可用时，在「手动配对设备」中输入对方的私有 IPv4 地址和一次性配对码即可。本机会通过该地址的 UDP 47876 端口获取并验证对端身份 ID 与 TLS 监听端口，随后建立直连。端口也可手动填写；填写后直接向该 TLS 端口请求配对码证明并核对身份 ID 和证书公钥，UDP 47876 不通时仍可配对。配对码过期后可在对端设置页点击「更新配对码」，无需重启服务。发现列表中的在线状态依赖 mDNS 或子网广播；手动配对不依赖组播或广播，但要求所用查询端口及对端 TLS 端口可达。已配对设备按身份 ID 识别，不按 IP 识别；同一身份 ID 在新 IP 或端口被发现后，客户端会优先尝试最新发现的地址，再回退至仍有效的其他网卡地址，并异步进行带公钥固定的 TLS 连接。只有验证成功才更新保存的连接地址。发现包只是地址提示，不能单独改变信任关系或已保存地址。撤销设备信任后，该设备不能继续请求本机的共享清单、协作更新或素材。

## 协作画布

在「设置 > 局域网共享 > 团队房间」创建团队，或输入 8 位数字码发现团队。房间码只用于快速匹配，不是密码或授权凭据；内部使用随机节点身份派生的房间 ID，发现结果会显示多个同码房间以便选择。新设备向一个在线成员发起签名加入申请，任何现有成员都能批准或拒绝；获批后，同步追加的签名成员记录，成员之间无需逐一配对。团队成员权限平等，没有固定管理员，也不要求创建者持续在线。

成员可自行离开；最后一名成员需提议解散团队，避免留下无人可审批的孤立房间。被移除的设备可再次申请加入。移除其他成员或解散团队需先发起提案，再由提案时的成员集合中超过半数成员批准；投票成员离线时提案会保持待决。房间状态使用签名、追加式事件图保存并通过成员直连合并；8 位码不会授予读取权限。成员退出、被移除或团队解散后，历史成员仍可通过证书固定的只读通道获知最终成员状态，但其提交的事件不会写入当前账本，也不能访问房间清单、素材或画布。修改本机设备名称后，成员名称也会作为签名资料事件同步到各房间。手动配对设备的旧式共享清单仍保留原来的独立范围，不会因加入团队自动开放给团队成员。

在画布列表的「局域网协作」区域，可选择一个已加入的团队创建协作画布，或从个人画布创建协作副本。副本不会修改原个人画布；原画布继续使用自己的保存版本和历史记录。团队内所有成员可查看、编辑、重命名、归档和删除团队画布。房间更新日志与成员设备本地持久化；在线内容通过成员间直接 TLS WebSocket 同步，离线成员重连后以游标补齐。小团队采用成员直连，不依赖某一台创建设备中转，也不需要中心服务器。

共享内容包括标题、节点、连线、时间线、导演场景和素材引用。聊天、视口、选择及面板状态留在各自设备上。在线编辑会实时同步；断开连接后，本机缓存的待发送更新与已保存的远端更新会在设备重新连通时补齐。界面显示「同步异常」时，先检查共享服务和团队成员连接，并保持画布打开以等待重试。删除画布会同步删除标记，但不会删除成员设备上的素材文件。

画布中的在线成员、远端光标和选区属于临时协作状态，不写入画布历史。设备离线后，这些状态会消失。左上角协作状态栏默认收起成员列表，只显示「成员 N」；点击后展开纵向列表，查看成员名称、在线状态及素材声明数量，成员较多时列表可滚动。再次点击、点击外部或按 Esc 收起。状态栏提供「隐藏成员光标 / 显示成员光标」开关；该偏好保存在本机，重启后保留，不改变其他设备的显示，也不关闭在线成员和远端选区反馈。

连续编辑按短时间窗口合并发送，不必等待停止拖动或输入。接收端先更新节点和文字，再在后台拉取缺失素材，文件传输不阻塞内容显示。素材尚未到齐时移动或编辑节点，会保留共享素材引用，文件到齐后自动显示。

首次打开协作画布也先加载内容并进入编辑，缺失素材加入后台队列；某个素材来源离线或传输失败时，画布仍可打开。

新增素材时立即启动登记与同步，不等待上一整批文件结束。登记/哈希准备和下载分别限制为最多 3 个文件并行，逐个完成、逐个显示；新增的小文件可与正在处理的大文件并行。若画布引用先到、素材清单后到，清单落盘通知会立即触发补查和拉取，不再只等定时轮询；下载优先尝试清单声明的可信持有设备。这里的“立即”表示及时启动传输，文件完成时间仍取决于大小、磁盘和网络速度。

桌面端的文件读取、哈希校验和 TLS 流传输由 Go HTTP 请求 goroutine 并发执行，由 Go 运行时调度到系统线程；前端只调度异步任务，不在界面线程读取和校验整个大文件。画布更新、成员/素材状态查询、文件准备和文件下载是独立通道；状态查询延迟不占用文件传输任务，文件传输也不阻塞状态刷新。应用级后台队列新增任务后立即唤醒，并可同时处理不同画布或同一画布中新加入的素材。状态查询失败单独显示并重试，图文编辑继续同步；画布持久更新与本机队列的写入仍保持串行，避免并发写覆盖。

协作画布的「版本记录」读取本机已持久保存的协作更新日志，与个人画布的历史和修订号分开。列表最多展示 100 个历史检查点，较长日志按更新数量选取检查点；预览按当时的内容哈希解析本机素材，尚未取得的历史素材可能暂不显示。列表时间表示更新到达本机的时间，各设备可能不同。设备离线或重新打开画布后仍可读取已保存的协作历史，新到达的更新可通过刷新列表查看。

恢复历史前会保留本机草稿。恢复内容作为新的协作编辑写入持久更新日志并同步给成员，允许恢复历史中已删除的节点；画布名称、本机聊天、视口和界面偏好保持当前值。发送失败时保留本机恢复结果和待发送更新，显示待同步错误，连接恢复后继续发送。

## 共享素材

资源清单保存素材元数据和内容哈希，素材本体由持有设备通过加密直连传输，不经中心服务中转。接收设备校验内容哈希后，将素材映射为本机资源；各设备的资源 ID 可以不同。素材尚未传到本机时，相关画布内容仍可继续编辑，但对应媒体可能暂时不可用。所有持有该素材的设备都离线时，素材也暂时无法获取。

画布上传图片、视频或音频时，优先用本机持久资源登记共享清单，临时预览地址不会作为对端的文件位置。只有临时地址的素材会先转为本机资源，再发布内容哈希；视频预览图与视频本体分别处理。

上传进度和上传错误属于本机操作状态，不发送给其他成员。素材登记与下载在后台进行，即使某个文件暂时读取失败，节点、连线和文字仍继续双向同步。已完成的文件逐项显示；失败文件保留待重试状态，其他文件继续处理。同一设备上的后台队列与画布同时请求相同素材时复用一次传输。素材登记和导入使用独立的 30 分钟请求超时，不沿用普通业务请求的 4 秒超时；文件大小与内容哈希仍由接收端校验。

接收完成后直接使用已校验的本机资源与清单声明，不再重复登记、计算同一文件的哈希。清单声明发布失败时，已下载文件仍可显示，声明保留到后台重试。浏览器内的资源映射缺失或过期时，优先从本机后端恢复并检查文件；本机已有完整文件时，无需等待来源设备上线。

桌面应用启动时会检查本机已映射的素材文件，之后每 5 分钟重新确认一次，不依赖共享服务是否开启。状态为「存在」表示最近巡检时找到文件，「缺失」表示确认文件已不在本机，「待确认」表示尚未检查或遇到暂时无法判定的错误。巡检不会删除清单条目或素材记录，也不会每次重新计算完整文件哈希；传输时仍会校验内容。若文件恢复，下次巡检会更新本机状态。

画布左上角协作状态栏中的「本机素材」计数表示当前设备已映射的素材数；「待同步」表示本机尚缺的素材。其他设备旁的「声明」计数仅来自共享清单的发布设备信息，**不是该设备当前仍持有素材的证明**。缺失素材由应用级后台队列持续重试，不要求画布保持打开；设备重新连通后再查看计数和失败状态。也可以在「设置 > 局域网共享」的共享清单中查看内容哈希、本机文件状态和手动导入素材。

局域网共享仅在用户启动后监听可用网卡的私有 IPv4 地址；桌面业务 API 不随共享服务暴露到这些地址。桌面 API、节点身份和本地资源归属的技术边界见 [HTTP API](../backend/http-api.mdx) 与 [数据库结构](../backend/backend-database.mdx)。
