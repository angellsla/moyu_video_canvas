# 局域网共享与协作画布

## 连接设备

在「设置 > 局域网共享」中启动共享服务。在「本机设备名称」输入名称并保存，在线时发现列表会随新的 mDNS 广告更新，无需重启。清空后使用系统设备名称。名称只用于显示，设备身份由固定的公钥指纹识别。给其他设备设置的本地备注与本机名称相互独立。

共享服务启动时会尝试在每块可用网卡的私有 IPv4 地址上监听；某个地址绑定失败时，其余成功监听的地址仍可使用。支持多播的网卡分别发布 mDNS 服务，并每 20 秒重新查询一次。对于无法传递 mDNS 的虚拟网卡等链路，设备还会每 10 秒向各已监听网卡所在子网的定向广播地址发送 UDP 47876 发现信息；它不会向所有网段或跨路由器广播。发现包只用于显示设备地址，配对仍须验证 TLS 指纹和配对码。设置页列出实际监听地址和本机 mDNS 注册状态，后者不保证对端能收到组播。启动后若新增或移除网卡，关闭再开启共享服务以刷新监听列表。虚拟网卡或 VPN 网卡如具备私有 IPv4 地址，也可能参与发现；请按实际网络连接和防火墙设置控制可达范围。

同一局域网中的设备会尝试自动发现；发现不可用时，在「手动配对设备」中输入对方的私有 IPv4 地址和一次性配对码即可。本机会通过该地址的 UDP 47876 端口获取并验证对端指纹与 TLS 监听端口，随后建立直连。端口也可手动填写；填写后直接向该 TLS 端口请求配对码证明并核对证书指纹，UDP 47876 不通时仍可配对。配对码过期后可在对端设置页点击「更新配对码」，无需重启服务。发现列表中的在线状态依赖 mDNS 或子网广播；手动配对不依赖组播或广播，但要求所用查询端口及对端 TLS 端口可达。撤销设备信任后，该设备不能继续请求本机的共享清单、协作更新或素材。

## 协作画布

在画布列表的「局域网协作」区域创建协作画布，或从个人画布创建协作副本。副本不会修改原个人画布；原画布继续使用自己的保存版本和历史记录。与创建设备配对的可信设备可在各自的画布列表中同步并打开协作画布，无需逐画布邀请；成员设备之间无需互相配对。所有成员可以编辑内容；画布创建者负责重命名、归档、恢复和删除。协作更新和在线状态经创建设备转发；创建设备离线时，本机编辑先持久保存，待其重新连接后再传给其他成员。

共享内容包括标题、节点、连线、时间线、导演场景和素材引用。聊天、视口、选择及面板状态留在各自设备上。在线编辑会实时同步；断开连接后，本机缓存的待发送更新与已保存的远端更新会在设备重新连通时补齐。界面显示「同步异常」时，先检查共享服务和对端连接，并保持画布打开以等待重试。删除画布会同步删除标记，但不会删除成员设备上的素材文件。

画布中的在线成员、远端光标和选区属于临时协作状态，不写入画布历史。设备离线后，这些状态会消失。左上角协作状态栏默认收起成员列表，只显示「成员 N」；点击后展开纵向列表，查看成员名称、在线状态及素材声明数量，成员较多时列表可滚动。再次点击、点击外部或按 Esc 收起。状态栏提供「隐藏成员光标 / 显示成员光标」开关；该偏好保存在本机，重启后保留，不改变其他设备的显示，也不关闭在线成员和远端选区反馈。

连续编辑按短时间窗口合并发送，不必等待停止拖动或输入。接收端先更新节点和文字，再在后台拉取缺失素材，文件传输不阻塞内容显示。素材尚未到齐时移动或编辑节点，会保留共享素材引用，文件到齐后自动显示。

## 共享素材

资源清单保存素材元数据和内容哈希，素材本体由持有设备通过加密直连传输，不经中心服务中转。接收设备校验内容哈希后，将素材映射为本机资源；各设备的资源 ID 可以不同。素材尚未传到本机时，相关画布内容仍可继续编辑，但对应媒体可能暂时不可用。所有持有该素材的设备都离线时，素材也暂时无法获取。

画布上传图片、视频或音频时，优先用本机持久资源登记共享清单，临时预览地址不会作为对端的文件位置。只有临时地址的素材会先转为本机资源，再发布内容哈希；视频预览图与视频本体分别处理。

桌面应用启动时会检查本机已映射的素材文件，之后每 5 分钟重新确认一次，不依赖共享服务是否开启。状态为「存在」表示最近巡检时找到文件，「缺失」表示确认文件已不在本机，「待确认」表示尚未检查或遇到暂时无法判定的错误。巡检不会删除清单条目或素材记录，也不会每次重新计算完整文件哈希；传输时仍会校验内容。若文件恢复，下次巡检会更新本机状态。

画布左上角协作状态栏中的「本机素材」计数表示当前设备已映射的素材数；「待同步」表示本机尚缺的素材。其他设备旁的「声明」计数仅来自共享清单的发布设备信息，**不是该设备当前仍持有素材的证明**。缺失素材由应用级后台队列持续重试，不要求画布保持打开；设备重新连通后再查看计数和失败状态。也可以在「设置 > 局域网共享」的共享清单中查看内容哈希、本机文件状态和手动导入素材。

局域网共享仅在用户启动后监听可用网卡的私有 IPv4 地址；桌面业务 API 不随共享服务暴露到这些地址。桌面 API、节点身份和本地资源归属的技术边界见 [HTTP API](../backend/http-api.mdx) 与 [数据库结构](../backend/backend-database.mdx)。
